# Calculadora Média

**Descrição**

Este projeto é um programa simples desenvolvido em Python para calcular a média das notas de um aluno.

O usuário informa as notas, e o programa realiza o cálculo automaticamente, apresentando a média final.

**Tecnologias Utilizadas**

Python versão 13.13

**Como instalar e Executar**
1. Baixar o Python
2. Clonar o projeto
3. Abrir a pasta
4. Copiar o projeto
5. Processar

**Exemplo de uso de Demonstração**

```
=== Sistema de Notas do Aluno ===
Digite a primeira nota:8
Digite a segunda nota:7
A média final é: 7.50
Status: Aprovado!


=== Sistema de Notas do Aluno ===
Digite a primeira nota:2
Digite a segunda nota:3
A média final é: 2.50
Status: REPROVADO.
```
